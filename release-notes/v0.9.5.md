This release brings update controls into the About dialog and makes update notifications easier to find.

## Improvements

- Check for updates, read release notes, and install updates from the About dialog
- Show the update notification badge on the About sidebar entry
- Keep automatic update checks alongside the manual update controls
- Add the current version and a feedback email link to the About dialog
