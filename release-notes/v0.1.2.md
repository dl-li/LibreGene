Patch release fixing a startup crash on Linux and improving packaging.

## Fixes

- **Flatpak / minimal Linux sessions no longer crash at startup** — the system tray library (libayatana-appindicator3) is absent in the GNOME Flatpak runtime, and the tray crate panicked instead of failing gracefully. The app now probes for the library first and simply runs without a tray icon when it is missing; closing the main window then quits normally instead of hiding it with no way back

## Improvements

- **Enzyme filter selection persists** across restarts instead of resetting to "unique + twice"
- **macOS dmg now includes a bilingual README** explaining how to allow the unsigned app through Gatekeeper
