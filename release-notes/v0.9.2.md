This release adds Chinese localization and unified project history, improves navigation and MCP integration, and includes reliability fixes across sequence, alignment, MSA, primer, and file workflows.

## New Features

- **Chinese interface** — select Chinese or English in Settings, with localized menus, dialogs, context actions, and session history
- **Unified undo/redo history** — use one session history and mutation model across ordinary sequence and MSA projects
- **Selectable primer Tm display modes** — compare full-duplex and 3′ matching-region Tm values with configurable display options
- **Search and navigation feedback** — highlight all sequence-search matches and use unified selection and navigation capsules

## Improvements

- Streamlined new-sequence creation and MSA workflows, with faster MSA pairwise calculations and lazy-loaded plugin dialogs
- Expanded MCP editing with atomic feature operations, sequence conversion, plasmid-map rendering, structured views, and clearer response contracts
- Map rendering now consistently produces JPG images, while restriction-enzyme details are opt-in to keep agent responses focused

## Bug Fixes

- Preserved each alignment's algorithm, reverse-read orientation, and statistics across GenBank save/reopen round trips
- Distinguished complete PCR product lengths from template spans and 5′ tails in primer design and binding tests
- Made feature translations authoritative from current DNA; imported GenBank translations are reference-only and translation qualifiers are not rewritten
- Retried sequence recomputation after concurrent edits, tracked alignment revisions correctly, and propagated primer update failures
- Included all cut pairs in gel digests, cleared stale MSA selections, and kept CDS translations synchronized
- Enforced FASTA alphabet and size validation on all input paths and added support for inline ABIF trace arrays
- Preserved forward feature strands during GenBank round trips and improved annotation-click selection behavior
