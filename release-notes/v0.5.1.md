Integration release centered on the embedded MCP server: a session workspace for staging sequence fragments, a leaner tool surface, and one uniform response envelope — plus a round of alignment-view and sequence-editing fixes.

## New Features

- **Session workspace for agents** — `add_to_workspace` stages a project fragment (selected by feature, by region, or by enzyme digest, with overlapping annotations carried along) in a session-scoped in-memory workspace; open projects are implicit members, and sequence-taking tools accept a workspace hash (`fwd7`, or the swapped `rev7/fwd7` pair for the reverse complement) as sequence input
- **Optional MCP authentication** — bearer-token verification can be turned off, with a reworked agent setup prompt

## Improvements

- **MCP tool surface consolidation** — dropped `list_species`, `close_project`, `search_sequence` and `search_enzymes`; split primer inspection into `test_primers` (with amplicon size for fwd+rev pairs); renamed `list_projects` to `list_workspace`; every tool description follows one skeleton (purpose, inputs, Returns, caveats)
- **Uniform MCP responses** — every tool answers with one envelope `{ok, message, projectId?, unit?, text?, sequenceHash?, revCompHash?, ...}`; counts use the `...Count` suffix (`mismatchCount`/`insertionCount`/`deletionCount`); `design_primers` reports a structured `product` span and `unit`; `find_orfs` uses one shape in both modes; `convert_sequence` items carry `unit` and hash their output sequence
- **Leaner overview digest** — single-cutter enzymes group by top-strand cut position ("N + names" per line), double-cutters are named, and the primer section lists each stored primer's sequence and type
- **Alignment view** — feature bars bridge insertion slots, insertion dashes always render, and Prev/Next navigation jumps between notable sites (mismatches, insertions, deletions)
- Plain-text protein files (`.prot`, `.fa`/`.fasta`) open as protein sequences

## Bug Fixes

- Chromatogram anchors sort by display direction, stopping origin-wrap backtracking
- Alignment lane bases merge into run tspans with per-character positioning, fixing scroll jank with many reads
- Primer display gaps consolidate via a state-machine Gotoh traceback
- Restored cursor/selection applies before paint to stay in sync with sequence edits; the cursor hides after inactivity instead of clearing; deleting a selection parks the cursor at the deletion point; replace-paste selects the pasted range; pasted annotations reverse-complement when the pasted text is flipped
- MCP `save_file` region-selector errors return an in-band `ok:false` rejection instead of a protocol error
