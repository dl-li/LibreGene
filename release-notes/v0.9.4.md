This release introduces built-in update checks and signed downloads from the LibreGene update service.

## New Features

- Check for updates manually or automatically at startup and every 24 hours
- Show a sidebar notification when a new version is available
- Download, verify, and install updates directly on macOS and Windows
- Publish the latest installers and update manifest automatically to Cloudflare R2

## Notes

- Linux Flatpak users are directed to the latest release instead of updating in place
- Updates are signed and verified before installation
- This is the first release with the built-in updater; earlier versions must install it manually
