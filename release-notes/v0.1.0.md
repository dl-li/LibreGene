First public release of **LibreGene** — a lightweight cross-platform desktop plasmid editor, free and open-source under GPL-3.0.

> ⚠️ **Early development** — APIs and file formats are not yet stable. Tested on macOS and Windows; Linux builds are unverified.

## Highlights

- **Feature annotation** — inline CDS/mRNA translation, auto-detection of common features via the pLannotate database, ORF search on all six frames, compound (multi-segment) features, enriched GenBank I/O preserving colors and primers
- **Primers** — binding visualization with mismatches, annealing region and nearest-neighbor Tm; assisted design for fragment amplification, OE-PCR and site-directed mutagenesis, with optional restriction-site tails
- **Codon optimization** — 9 species usage tables (Kazusa), three strategies (best codon / match usage / harmonize), CAI & GC% preview before applying
- **Restriction enzymes** — 900+ enzyme database with methylation-aware filtering, unique/twice/blunt/Type IIS categorization, custom enzyme sets
- **Sequence alignment** — import Sanger .ab1, FASTA or GenBank reads against the reference, with mismatch/indel highlighting and per-read identity
- **RNA secondary structure** — MFE folding (Turner 2004) via WebAssembly, interactive force-directed layout
- **MCP / LLM agent integration** — embedded MCP server (18 tools) lets an external LLM agent operate the open plasmid like a real user, with the UI updating live
- **And more** — SVG plasmid map with multi-line wrapped sequence view, DNA/RNA/protein modes, plugin system, multi-project tabs, full undo/redo, GenBank/SnapGene/FASTA I/O
