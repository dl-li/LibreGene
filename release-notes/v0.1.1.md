Patch release with fixes for lowercase-sequence handling and editor rendering.

## Fixes

- **Lowercase bases handled consistently** — GenBank files that keep lowercase sequence no longer break downstream features: restriction-site matching, peptide search (stop-codon re-check), primer alignment seeding, and the frontend complement operation all treat lowercase bases correctly
- **CDS amino-acid numbering hover** — the tooltip now triggers across the whole base range instead of only on part of it
- **Alignment view spacing** — widened the gap between alignment lanes and feature tracks so overlapping reads no longer crowd the feature annotations

## Packaging

- Linux builds are now published as **Flatpak** only (amd64 + aarch64); deb/AppImage are no longer produced
