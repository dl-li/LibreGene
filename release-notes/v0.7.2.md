This release fixes the macOS traffic-light position in release builds.

## Bug Fixes

- **macOS traffic-light position** — release builds activated the decoration plugin, whose inset semantics differ from tao's `trafficLightPosition` (the value everything was tuned against in dev, where the plugin never activates), placing the window controls too close to the top-left corner; macOS now relies on tao's native positioning, which is also stable across display and focus changes. Windows and Linux are unaffected — the plugin still draws the custom window controls there.
