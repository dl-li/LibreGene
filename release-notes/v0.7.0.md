This release adds a SnapGene-style double-strand view, smarter alignment-aware primer display, and a reorganized plugin system with fully declarative hooks, plus a batch of interaction fixes.

## New Features

- **Show Both Strands view** — SnapGene-style ruler rendering both strands; toggle from the View menu
- **Alignment-driven primer display** — primers align against the template with gap/insertion placeholders; incidental edge matches dissolve into the primer's hanging tail
- **Always-expand primers mode** — on by default; feature/primer expand and label settings moved from the Settings dialog to the View menu
- **Enzyme display caps** — cap the number of displayed cut sites per enzyme via settings; enzymes requiring undetectable methylation (5mC/5hmC) are always marked as required
- **Plugin author field** — optional, shown in the Plugins window

## Improvements

- **Plugin system reorganization** — plugins now live in `builtin/` and `example-plugin-*/`, and plugin hooks are fully declarative (no more `storageKey` in the plugin state contract)
- **Gel dialog polish** — deep-blue accent, editor-style enzyme badges, larger lane labels, and wells pushed down for multi-line enzyme names
- **Primer deletion safeguard** — Backspace or the context menu asks for confirmation before deleting a primer
- **Drag selection** — Tm badge rounds to whole degrees; dragging back to the origin collapses the selection
- **Ruler styling** — the double-strand ruler is darker and thicker
- **README** — rewritten bilingually around reorganized screenshots, including a Digest and Run Gel section

## Bug Fixes

- Delete/Backspace, typing, and paste now act on translation selections; Backspace deletes a selected primer
- Primer hover hit area shrunk and sized to the visible band so it no longer blocks adjacent elements
- Enzyme hover shows the per-site methylation reason
- Wheel scrolling is contained inside sidebars and self-contained dialogs, no longer rubber-banding the window
- The first query base in primer alignment can now align diagonally
