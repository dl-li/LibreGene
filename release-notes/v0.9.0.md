This release keeps all projects in a single window, strengthens project isolation and file persistence, and includes several platform and editor fixes.

## Improvements

- **Unified project window** — open multiple projects as sidebar tabs in the main window instead of managing separate windows

## Bug Fixes

- Isolated project edits and file persistence so changes and saves always target the intended project
- Preserved feature annotations when copying and pasting sequences between projects
- Restored the main window when launching LibreGene while it is already running
- Used light native title bars on Windows and removed blank space in the dotplot dialog
