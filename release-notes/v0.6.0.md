This release introduces a continuous horizontal view mode, a distributable Digest and Run Gel plugin for in-silico digestion and gel simulation, a reworked menu layout, and a round of enzyme database corrections.

## New Features

- **Continuous (horizontal) view mode** — switch between wrap and continuous layout from the View menu; continuous mode renders the whole sequence on one line with horizontal scrolling and a dedicated feature scrollbar
- **Digest and Run Gel plugin** — pick enzymes and simulate the digest on a virtual gel; ships as a self-contained distributable plugin
- **Reworked menus** — View sits after Edit with ORF/GC toggles and sticky left-click; Codon Optimization moves to the Edit menu; My Enzymes lists atop Enzyme Set

## Improvements

- **Distributable plugins** — Dotplot is now a self-contained distributable plugin; built-in plugins collapse by default in the Plugins window
- **Continuous-mode polish** — alignment labels hug the read's right edge and pin to the viewport with a fading backdrop, the hide button gets its own chip, the navigator is centred below the top scrollbar, and jumping to a site centres it in the window; feature labels clamp flush with the alignment labels' right edge
- **MCP workspace lifecycle** — workspace fragments are removed when their source project (or the main window) closes
- **Resource caps** — workspace fragments, input file size, and MCP connections are capped against unbounded growth

## Bug Fixes

- Corrected the AbaSI recognition site from a 1-bp C to the 22-bp CNNNNNNNNNNN/NNNNNNNNNG window
- Corrected MlyI/SchI elucidate and TspRI/TscAI overhang length; marked PvuRts1I-family enzymes (FspEI, MspJI, SgeI, LpnPI) methylation-dependent
- FspEI no longer shows in the on-sequence enzyme display
- Scrollbar track presses in continuous mode continue as a drag
