This release adds alignment and digestion overviews, faster sequence input, and more flexible primer displays, alongside reliability fixes across editing and file workflows.

## New Features

- **Alignment overview** — inspect and navigate sequence alignments with a dedicated overview diagram
- **Digestion overview** — review restriction digestion results in a dedicated dialog with a fixed header while scrolling
- **Sequence shortcut input** — enter sequences more quickly with shortcut input support

## Improvements

- Use `.libregene.gbk` and `.libregene.gpt` as native sequence file suffixes
- Allow hiding primers from the editor and show selected primer or primer-pair Tm values in the selection capsule
- Preserve primer sequence case in the editor and improve navigation and selection capsule styling

## Bug Fixes

- Synchronized sequence edits with selection updates and prevented hover scroll anchoring jumps
- Prevented memory project ID collisions and ignored dirty markers for closed projects
- Selected only the basename in native save dialogs and rejected empty replacement files before editing
- Aligned primer bases with match markers and excluded virtual ORFs from copied annotations
