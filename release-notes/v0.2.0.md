Feature release centered on Sanger chromatogram (AB1) display, a redesigned primer-alignment view, and much richer read-alignment rendering.

## New Features

- **AB1 chromatogram display** — opening a `.ab1` file now shows the Sanger trace alongside the sequence, and alignment reads with trace data can expand a chromatogram band under their lane; bands collapse behind a per-track label toggle
- **Reads align across large internal template deletions** — a read spanning a big deletion in the template is now split-aligned onto both flanks instead of failing to place
- **Alignment gaps and insertions render as placeholders** — large indels are drawn as compact dot-pair markers (with hover highlighting per insertion, group hover, and a right-margin label) instead of stretching the layout; an insertion popover lists the inserted bases
- **Primer alignment details redesigned** — the primer-vs-template view now shows flanking context, position markers, base-level highlighting, and unaligned 5' tail overhangs
- **Linearize / Circularize toggle** — DNA projects can switch topology from the Edit menu
- **Enzyme context menu** — right-click an enzyme site for related-enzyme navigation; enzyme lists auto-scroll while dragging
- **Sidebar project tabs** — long names scroll on hover, and tabs can be reordered with a long-press drag
- **Feature deletion shortcut** — clicking a feature then pressing Backspace once deletes the feature, twice deletes the underlying sequence

## Improvements

- **Tm now matches SnapGene** — melting temperatures use the SantaLucia & Hicks (2004) initiation parameters
- **Hidden alignment tracks persist per file** — tracks you hide stay hidden across reloads
- **Nav bar interactions** — left-click runs the default action, right-click opens the menu
- **Overlapping feature labels** — hovering a feature raises its label above the crowd
- **Map watermark simplified** — feature labels are hidden in the watermark, keeping just the plasmid name and size
- **Dialogs** — Esc closes the search bar and layered dialogs; the feature dialog requires resolving a pending location edit before closing; the primer dialog defaults to a wider minimum width
- **Save dialog prefills the name** entered for unsaved projects, and duplicate feature names are allowed when creating features
- **Homebrew tap updates automatically** on each release

## Bug Fixes

- Features with identical ranges now all render instead of being deduped
- Clicking blank canvas areas clears the selection
- Primer alignment windows extend past reverse-primer footprints and wrap correctly at the circular origin
- Newlines are stripped from primer sequences parsed from wrapped GenBank notes
