This release adds a session edit log with safe rollback, restores native window chrome, and includes a set of editor and platform fixes.

## New Features

- **Session Edit Log** — review every change made during the current session, see which changes have been saved, and roll back unsaved edits to a previous state

## Improvements

- **Native window chrome** — uses the operating system's window decorations for a more consistent look and reliable window controls
- **Typography and rendering** — declares Cascadia variable font weights and sharpens enzyme connector lines at low resolution

## Bug Fixes

- Prevented ORF searches from returning stale results after sequence edits
- Preserved primer IDs when importing pasted primers and restored focus to the new-primer sequence input
- Kept methylation settings user-level rather than marking sequence files as modified
- Fixed reverse-column lookup for track plugins and disabled the navigation glass effect on Linux
