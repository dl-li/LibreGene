Feature release centered on enzyme supplier data and a new supplier detail dialog, SnapGene history snapshots, and an expanded embedded MCP toolset.

## New Features

- **SnapGene history snapshots** — `.dna` files expose their history tree via Edit → History; open any snapshot as a new in-memory project carrying that node's complete subtree history plus the features/primers as of that point, and keep opening nested snapshots inside it (history is view-only; Save As stays GenBank)
- **Enzyme supplier data & provider filter** — imported NEB / BestEnzyme / Thermo provider metadata (buffer compatibility, temperature, methylation, methylation sensitivity); filter the enzyme set by provider in the nav menu, intersected with the Enzyme Set filter
- **Enzyme detail dialog** — double-click an enzyme label (or a row in the Enzyme Database dialog) to open a detail dialog with the full recognition site, cut positions, overhang, star activity, and a variant switcher showing per-variant supplier data, with collapsible related-enzyme (isoschizomer / neoschizomer) lists
- **MCP `convert_sequence`** — the old `optimize_cds` tool is replaced by a unified batch conversion tool: dna↔rna (T↔U, optional revComp), dna/rna→protein translation, protein→dna/rna reverse translation with codon optimization, and dna→dna codon optimization, with per-item error isolation

## Improvements

- SnapGene history dialog renders as a flat vertical timeline, and its entry moved into the Edit menu as History
- Nav menu buttons show a caret affordance on hover
- Supplier field values and enzyme data are fully in English, with star activity reformatted as buffer lists
- Alignment chromatogram bands now cut cleanly at deletions, insertions, and circular-join wraps instead of bridging artifacts — matches/mismatches stay connected, reads render on the row containing the join wrap

## Bug Fixes

- Reject crafted SnapGene feature coordinates at parse and export instead of accepting malformed data
- Show the user-entered name on the map for new sequences and mark new projects dirty
- Ellipsize long plasmid names in map view to avoid overlap
- Exported enzyme JSON goes to stdout instead of a hardcoded home path
- Guard against a missing project when plasmid length is read
