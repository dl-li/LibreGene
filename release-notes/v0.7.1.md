This release adds per-strand sequence text colors, a rebuilt Settings dialog, and single/double-strand view refinements, and fixes the legacy window chrome (small corner radius, dark window border, mispositioned traffic lights) seen in Homebrew-installed builds on the latest macOS.

## New Features

- **Per-strand text colors** — color sequence text per strand from the selection context menu; colors persist in GenBank files and import from SnapGene `.dna` files
- **About dialog** — version, developer, and repo star link
- **Per-molecule-type sequence case display** — upper/lowercase display is now a per-molecule-type setting

## Improvements

- **Settings dialog rebuilt** — section navigation with a cleaner row layout
- **Text Color menu** — single context entry with nested submenus, plus a View-menu toggle; the strand submenu is skipped in single-strand view, defaulting to both strands
- **Expand toggles renamed** — now "Expand All Features/Primers"
- **Double-strand view** — looser block vertical spacing; enzyme tooltip connector routes below the ruler with a background-colored casing that stays inside the box

## Bug Fixes

- **macOS window chrome** — release builds were linked against an older macOS SDK, so macOS rendered legacy window styling (small corner radius, dark border, off-position traffic lights); CI now builds with the latest Xcode/SDK
- Annotated paste over a selection now supersedes covered features
