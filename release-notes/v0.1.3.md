Feature release adding multi-record FASTA splitting and a much faster sequence alignment engine.

## New Features

- **Multi-record FASTA files can be split on open** — opening a FASTA file with more than one sequence now lists the records and offers to open each as its own project, or just the first one
- **RNA fold watermark highlights the current selection** — selected bases are marked directly on the secondary-structure overlay
- **Plasmid map moves to the editor nav bar and becomes a plugin** — the Map entry now lives in the bottom nav menu of each project (where it belongs), and can be turned off entirely in Settings → Plugins
- **Editor background picker** — right-click the editor canvas and choose Background ▸ None / Map / Folding to show a dimmed plasmid map or RNA fold behind the sequence; the choice is remembered per molecule type (DNA / RNA / protein) and applies across all files of that type

## Improvements

- **Sidebar fades out scrolled-off projects** — when the file list overflows, the hidden edge now fades away instead of cutting items off mid-row

- **Sequence alignment is dramatically faster on long reads** — alignment now uses seeded, banded Smith-Waterman instead of a full-matrix search; aligning a ~15 kb read against a ~15 kb plasmid drops from several seconds to well under a second, and results on repetitive templates are now deterministic
- **Sidebar keeps its top and bottom buttons fixed** — Open/New and the bottom function buttons no longer scroll away with a long file list; only the recent/opened file lists scroll
- **Windows window controls are more legible** — the minimize/maximize/close glyphs are larger and higher contrast
- **Enzyme set selection truly persists** across restarts (the stored value was saved but never parsed back)
