This release adds a floating continuous-mode overview, per-residue protein property tracks, high-contrast sequence text colors, and Windows ARM64 builds, alongside substantial editor performance and primer rendering improvements.

## New Features

- **Continuous sequence overview** — a floating linear map with a viewport indicator replaces the top scrollbar; click or drag to navigate long sequences
- **Protein property tracks** — per-residue hydrophobicity, charge, polarity, volume, and secondary-structure propensity tracks, with color legends in the View menu
- **High-contrast text colors** — a new Settings option improves sequence text readability and applies to existing colored sequences
- **Thick Feature Lines** — a new View-menu toggle increases feature line weight
- **Settings transfer and default-app registration** — import or export user settings and register LibreGene as the default application for supported files
- **Windows ARM64 builds** — native MSI and NSIS installers are now available alongside x64 builds

## Improvements

- **Faster editing and primer analysis** — primer recomputation is parallelized and narrowed to affected regions, and editor rendering and state handling have been streamlined
- **Feature and primer menus** — display options are now available directly from the Features and Primers menus as well as the View menu
- **Expanded primer layout** — increased track spacing keeps raised labels clear of adjacent primer bands
- **Text color refinements** — a more balanced palette, clearer editing feedback, and a Settings warning when Show Text Color is disabled
- **Agent navigation** — agent-locked windows automatically scroll to and select regions changed through MCP

## Bug Fixes

- Primer tracks now render every binding site, including alternative alignments, with alternative alignment diagrams correctly positioned
- Restored continuous-mode scrolling, horizontal wheel scrolling, and feature label visibility
- Preserved read bases in alignment models and prevented stale codon writes and misattributed alignments
- Preserved circular drag direction across the sequence origin, and retained dirty state and edit history when edits fail
- Corrected multi-lap primer binding endpoints and primer label collisions in Expand All Primers mode
- Kept transferred primer IDs unique and cleaned up workspace fragments after project rekeying and eviction
